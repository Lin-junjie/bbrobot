# 热流道压力降计算软件

计算注塑熔体**流经热流道系统**（主射嘴 → 分流板流道 → 热嘴 → 热嘴尖）时的分段压力降与总压力降，带图形界面，拖动“注射量”等滑块时图表实时随动。

## 功能

- **粘度模型**：Cross-WLF（Moldflow 参数格式：n、τ\*、D1、D2、D3、A1、Ã2）
- **内置材料库**：PP、HDPE、ABS、PC、PC/ABS、PA6、PA66、POM、PBT、PS、PMMA、PET；可在界面中“自定义…”输入实测牌号参数
- **截面类型**：圆形、方形、矩形、环形（如热嘴鱼雷/阀针周围的环形流道），编辑时实时显示截面图
- **并联支路**：每段可设并联数（如一出四热嘴为 4），流量按支路数平分
- **实时调节**：熔体温度、注射量、注射时间三个滑块，图表与结果表随动
- **图表**
  1. 分段压力降柱状图（含占比）
  2. 沿流动路径的压力分布
  3. 总压力降随注射量的变化曲线，并标出当前工况点
- **文件**：方案保存/打开（JSON）、结果导出 CSV、图表导出 PNG

## 安装与运行

需要 Python ≥ 3.10 且带 tkinter（Windows/macOS 官方安装包自带；Linux 需安装 `python3-tk`）。

```bash
pip install -r requirements.txt
python -m hotrunner
```

运行测试：

```bash
pip install pytest
python -m pytest
```

## 计算方法

1. 总体积流量 `Q = 注射量 / 注射时间`，每段单支路流量 `q = Q / 并联数`。
2. 采用 Kozicki 广义方法（对圆管即 Rabinowitsch 修正）求壁面剪切速率：

   `γ̇w = (a + b·n') / n' · 8V / Dh`，其中 `V = q / A`，`Dh = 4A / 周长`

   `n'` 为 Cross 模型在 `γ̇w` 处的局部幂律指数，迭代求解至收敛。
3. 壁面剪切应力 `τw = η(γ̇w, T) · γ̇w`，压力降 `ΔP = 4 τw L / Dh`。
4. 总压力降为流动路径上各段之和。

截面几何常数 `a`、`b`：圆形取 0.25 / 0.75；矩形与环形用牛顿流体精确解（级数/解析式）求出 `a + b = f·Re / 16`，再按 Kozicki 表分配 `a`、`b`。

**精度**：与圆管内 Cross 流体的精确积分解相比，偏差小于 3%，且结果偏大（偏保守）。

**假设与限制**

- 等温流动（热流道温控良好），不计剪切生热与压力对粘度的影响（库中 D3 = 0）
- 充分发展层流，不计弯头、分流处、入口收缩等局部损失
- 库中材料参数为同类牌号的典型值，只适合方案对比；精确计算请用实测牌号参数

## 代码结构

```
hotrunner/
  materials.py   材料库（Cross-WLF 参数）
  rheology.py    Cross-WLF 粘度与局部幂律指数
  geometry.py    圆形 / 矩形(方形) / 环形截面
  solver.py      分段压力降计算
  plotting.py    图表与截面绘制
  gui.py         tkinter 图形界面
tests/           单元测试（含与圆管精确解对比）
```
